## Summary of Contents

Table S.1 presents the normalized weights for:

- 16 AI implementation challenges (CH1 to CH16), ranging in importance from 0.130 (CH1) to 0.027 (CH16).
- For each challenge, five evaluation criteria (C1–C5) with their relative weights (e.g., CH1: C1=0.30, C2=0.25, C3=0.20, C4=0.15, C5=0.10).

These weights were derived from expert judgments (seven senior surgeons and an operating room manager) using the Best‑Worst Method, with an inconsistency ratio < 0.1.
